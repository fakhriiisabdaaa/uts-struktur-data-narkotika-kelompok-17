Pengambil Keputusan: Fakhri Sabda Lazuardi (002), Marsciano Tri Julian (025)
1.	Konteks
Aplikasi kali ini, memerlukan beberapa fitur, berupa pencarian, pengurutan, penghapusan, dan filter untuk mempermudahnya pengelolaan data putusam. Setiap fitur dibuat dengan pertimbangan struktur data yang sudah digunakan agar data asli tetap terjaga. 

2.	Keputusan
Kami memutuskan penggunaan beberapa metode berikut:
  1.	Pencarian:
Menggunakan Linear Search untuk mencari data berdasarkan ID Kasus, Nomor Perkara, dan ID Terdakwa. 
  2.	Pengurutan:
Kami menggunakan Insertion Sort untuk proses pengurutan. Pengurutan dilakukan pada Salinan data, agar data asli tidak berubah urutannya.
  3.	Filter:
Data akan diperiksa berdasarkan kriteria yang diinput(diisi). Jika beberapa kriteria diinput sekaligus, maka semua kriteria harus terpenuhi, jika tidak terpenuhi untuk semua data yang di import, maka tidak aka nada hasilnya.
  4.	Pencarian Riwayat:
Menggunakan pencarian pada stack tanpa merubah urutan Riwayat yang tersimpan.
  5.	Penghapusan:
Penghapusan dilakukan berdasarkan posisi indeks pada array.  Setelah data dihapus, data berikutnya akan bergeser untuk mengisi posisi indeks yang kosong.

3.	Alasan Pemilihan 
Linear Search dipilih karena data tidak harus dalam keadaan terurut untuk melakukan pencarian. Insertion Sort dipilih karena implementasinya cukup sederhana dan sesuai dengan jumlah data yang dikelola.
Kami juga memilih untuk mengurutkan salinan data agar urutan arsip asli tetap terjaga. Sementara itu, proses filter dibuat dengan memeriksa data satu per satu sesuai kriteria yang dimasukkan.
4.	Konsekuensi
Metode yang kami pilih cukup mudah diterapkan dan sesuai dengan kebutuhan aplikasi yang dibuat. Namun, untuk pencarian dan filter perlu memeriksa data satu per satu, sedangkan pengurutan menggunakan salinan data tambahan.
Dengan jumlah data sebanyak 50 putusan, metode tersebut masih cocok untuk digunakan.

5.	Keputusan Data
Dalam pengelolaan data CSV, kami menetapkan beberpaa ketentuan:
  1.	Setiap data atribut diawali dan diakhiri dengan tanda kutip dua(“) kecuali atribut idKasus, dan atribut dipisahka dengan koma(,)  
  2.	Berat barang bukti menggunakan berat netto, namun jika hanya ada berat bruto, maka berat brytto dijumlahkan keseluruhannya.
